# Контракты компонентов

Пакеты core находятся в `org.vlaskin.bot.utils.callback` и
`org.vlaskin.bot.utils.concurrent`. Они не требуют Spring или API платформы ботов.
Имена Java-модулей — `org.vlaskin.bot.utils.core` (core) и
`org.vlaskin.bot.utils` (starter).

## Блокировки по ключу

`LockByKey<K>` обеспечивает последовательный доступ внутри одного процесса
и экземпляра. Разделяйте экземпляр между обработчиками одного диалога.
Каждый успешный захват требует `unlock` в `finally`:

```java
locks.lockInterruptibly(dialogId);
try {
    handleDialog(dialogId);
} finally {
    locks.unlock(dialogId);
}
```

Если `lockInterruptibly` выбросил `InterruptedException`, вызывать `unlock`
не нужно. Ключ не может быть null; его `equals/hashCode` должны оставаться
неизменными до освобождения. Блокировки реентерабельны, не гарантируют
справедливость и удаляются после освобождения последним пользователем.
Порядок захвата разных ключей и межпроцессную синхронизацию определяет приложение.

## Callback-данные

`CallbackPayload` хранит код события и неизменяемые параметры.
`CallbackCodec` использует запятую как разделитель. Пустые параметры,
запятые и пробелы по краям параметров при кодировании запрещены.
При чтении пробелы по краям полей удаляются; внутри параметров сохраняются.

Код события должен быть непустым, стабильным и уникальным внутри протокола;
допустимы ASCII-буквы, цифры, `_` и `-`. Для enum используйте `CallbackEvent`,
а не `ordinal()`. Уникальность кодов проверяет приложение.

`CallbackParameters` проверяет количество параметров и читает строки,
целые числа и UUID. Индексы отсчитываются с нуля; строковые значения не обрезаются.
`CompactUuid` кодирует UUID в 22 URL-safe символа без padding и принимает
только каноническое представление.

Ошибочный ввод декодеров вызывает `IllegalArgumentException`; null в методах
`encode` вызывает `NullPointerException`. Ограничения размера, авторизацию
и защиту от повторного выполнения проверяет приложение. Кодек не шифрует данные.
