# История изменений

Описаны изменения публичных компонентов. Порядок публикации приведён в
[руководстве по релизам](RELEASING.md).

## Следующая версия

- Сокращён README; контракты компонентов вынесены в `USAGE.md`.
- Добавлена история изменений.
- Добавлен Maven Site с руководством, историей изменений, JavaDoc и
  отчётами покрытия обоих модулей; настроены проверка в PR и GitHub Pages.
- Сборка и публикация Pages ограничены веткой `main`, включая ручной запуск.

- Выделен `bot-utils-core` без runtime-зависимостей; starter подключает его
  транзитивно, сохраняя прежние координаты и API `PebbleService`.
- Добавлены блокировки по ключу с прерываемым ожиданием и очисткой
  неиспользуемых ключей.
- Добавлены callback-кодек, стабильные коды событий, проверка параметров
  и компактное представление UUID.
- Проверены отмена и гонки блокировок, ошибки шаблонов и параллельный рендеринг.
- Релизный workflow проверяет согласованность версий parent, core и starter.

## 1.0.0

- Первый выпуск Spring Boot starter: автоконфигурация Pebble и
  сервис рендеринга шаблонов сообщений `PebbleService`.
